# DNHS Underground Rap Club website

A responsive, dependency-free club website for the Del Norte Underground Rap Club, with meeting details, a first-visit guide, club leadership, FAQ, Instagram, and Discord links.

## Preview locally

From the repository root:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/`.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

## Content sources

Meeting time, room, club motto, and Discord invite are based on the `@dnhs_ugrc` profile. The 2026–27 board roster, activities, goals, and club expectations were verified from the club's August 29, 2026 leadership carousel.
