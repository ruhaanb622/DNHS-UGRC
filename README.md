# DNHS Underground Rap Club website

A responsive, dependency-free club website for the Del Norte Underground Rap Club, with meeting details, a first-visit guide, club leadership, FAQ, Instagram, and Discord links.

## Preview locally

From the repository root:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/`.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

## Content sources

Meeting time, room, club motto, leadership handles, Discord invite, and the Instagram follower snapshot are based on the public `@dnhs_ugrc` profile as viewed in August 2026.
